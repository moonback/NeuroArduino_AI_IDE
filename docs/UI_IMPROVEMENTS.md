# UI IMPROVEMENTS

Améliorations structurelles appliquées côté UX technique:
- Fiabilisation des retours d'état réseau (timeouts/retry) pour éviter états UI bloqués.
- Stabilité de la console/monitor série grâce au nettoyage websocket.

> Refonte visuelle premium complète non effectuée dans cette passe, car nécessiterait un chantier UI dédié multi-fichiers (design system, tokens, composants, animations).
